# Phase 1 Spec — $DASHA Cultural Tools

## Goals
Add light, on-brand utility to $DASHA without killing the meme.

## Features
1. **Studio Gating**
   - Public: 0+ $DASHA
   - Advanced: 50,000+ $DASHA
   - Full: 150,000+ $DASHA

2. **Burn-to-Mint cNFT**
   - Burn ~15,000 $DASHA → mint a compressed NFT (cultural artifact)
   - Uses Metaplex Bubblegum + Merkle tree
   - Metadata + image on Arweave/Irys

3. **Public Lobby** (lobby.getdasha.com)
   - Public rooms only (no DMs)
   - Wallet-signed auth
   - $DASHA tier flair / presence
   - Reactions, replies, pins (Full tier)
   - PartyKit real-time backend

## Out of Scope for Phase 1
- Voice
- Private channels
- Complex roles beyond holdings
- Token-gated entry (everyone can read)
