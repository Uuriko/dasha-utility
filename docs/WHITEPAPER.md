# $DASHA Whitepaper v1.1

## Cultural Tools for a Meme Token

$DASHA is a Solana meme coin rooted in the Red Scare / Dimes Square cultural sphere. This package adds lightweight utility while preserving the ironic, anti-tryhard spirit.

### Core Features

- **Studio Gating**: Hold $DASHA to unlock advanced meme tools.
- **Burn-to-Mint cNFTs**: Burn tokens to mint compressed NFTs (cultural artifacts) via Bubblegum.
- **Arweave Permanence**: Metadata and images stored permanently.
- **Public Lobby**: Discord/Telegram-style public rooms with $DASHA status, no DMs.

### Design Principles
- Soft utility over hard claims.
- Cultural framing first.
- On-chain minimalism (cNFTs for scale).

Full details in the Phase 1 specs and implementation guides in this repo.
